What the studio holds to

Four commitments, each with something you can check for yourself.

§1 Zero data PASS No analytics, no cookies, no third-party requests, in the app or on this page. The privacy record lists every category, and each one says none.
§2 Every value visible PASS Each parameter is shown and set by you. No hidden defaults, no black boxes, no “we’ll tune it for you.” See FreqCraft.
§3 Bought once PASS A one-time purchase at a fair price. No subscription, no ads, no upsell. It keeps working whether or not the studio ships another thing.
§4 Published process PASS The actual pre-release QA procedure, reproduced in full and kept current, including the defects it caught. Read the test report.
